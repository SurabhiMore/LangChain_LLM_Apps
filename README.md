# LangChain for LLM Application Development

This repository contains my notes, exercises, and sample projects from the **[LangChain for LLM Application Development](https://www.coursera.org/learn/langchain-llm-application-development)** course by Harrison Chase and Andrew Ng on Coursera.

---

## About the Course

**LangChain for LLM Application Development** is a short course that provides hands-on experience with building applications using **Large Language Models (LLMs)** and the **LangChain framework**. The course focuses on extending the capabilities of language models in real-world applications.

**Key Topics Covered:**

- **Models, Prompts, and Parsers:** How to call LLMs, provide prompts, and parse their responses.  
- **Memories for LLMs:** Techniques for storing conversations and managing limited context space.  
- **Chains:** Creating sequences of operations to build complex workflows.  
- **Question Answering over Documents:** Applying LLMs to proprietary data for practical use cases.  
- **Agents:** Exploring LLMs as reasoning agents for dynamic problem-solving.

**Outcome:**  
By the end of the course, you will have a foundation for creating robust LLM-based applications and experimenting with diffusion models in your own projects.
